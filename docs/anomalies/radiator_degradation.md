## Root cause

The radiator's emissivity dropped 40% (injected `radiator_degradation`; for example coating darkening or contamination). The same heat now leaves at a higher radiator temperature, and the conductively coupled nodes warm with it. Every temperature settles inside its limits, so only the comparison of the orbit-mean radiator temperature with the thermal prediction catches it.

## Recommended fix

Operations: reduce payload duty cycle to restore thermal margin, and update the thermal model and the expected orbit mean with the measured emissivity. Flight software: load the expected value per beta angle from thermal analysis, since the one in params.hpp is valid only at the default 30° beta.
