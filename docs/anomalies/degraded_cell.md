## Root cause

The battery's internal resistance doubled (injected `degraded_cell`; in a real 4S2P pack, for example one parallel string going open or cell ageing). Terminal voltage sags more under load, so the EKF's innovations jump until its R0 state catches up.

## Recommended fix

Operations: confirm with a second orbit of data, then reduce depth of discharge (payload duty cycle) and raise the LOAD_SHED threshold. Flight software: the EKF assumes capacity is known; add a capacity state so a fault that also loses capacity is tracked, and update the nominal R0 table after the event.
