## Root cause

The battery heater's switch failed closed (injected `stuck_on_heater`), so the 5 W heater runs whatever the thermostat commands. Housekeeping reports only the commanded state, so the only signature is extra load power and a warmer battery.

## Recommended fix

Operations: if the battery stays below its yellow limit, accept the extra 5 W and keep energy margin with payload duty cycling. Design: put two switches in series so a second one can open a stuck heater, and downlink heater current or switch state so a stuck heater is visible directly.
